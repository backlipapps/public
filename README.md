# Backlip — small, native ecommerce apps, one job each

Backlip builds small, native ecommerce apps and integrations — one merchant job per app — and
ships them through the platform marketplaces. Install and billing always happen on your
platform's own marketplace; pricing, plans, badges, and reviews live on each listing.

> A marketplace link below proves a public install destination for that platform — not
> identical cross-platform features. Each listing shows what that build supports.
