Catalog › BL Scrolling Announcement Bar

The easiest way to keep timely store messages visible — a free-shipping threshold, a promo code, a delivery update — without a theme-development task. Native versions for Shopify, Wix, Ecwid, BigCommerce, and the Shoper Appstore (PL).

Add multiple messages and manage them in one admin panel. Link each message to any page, category, or product. Control colours, gradient or solid backgrounds, fonts and font size, bar height, animation direction, speed, and spacing — or switch the animation off for a static bar. Live preview and pause-on-hover where the platform build supports them.

A marketplace link proves a public install destination for that platform — not identical cross-platform features. Each listing shows what that build supports.
